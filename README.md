# Unblock IMEI by Bray — Landing Page

## Isi paket
- `index.html` — struktur halaman
- `styles.css` — desain responsif Futuristic Premium
- `script.js` — interaksi navigasi mobile dan tahun footer
- `assets/logo-unblock-imei-by-bray.png` — logo dari Owner

## Menjalankan secara lokal
1. Ekstrak folder.
2. Buka `index.html` di browser, atau jalankan server lokal sederhana.
3. Pastikan koneksi internet tersedia untuk font Google Fonts.

## Publikasi
Website ini berupa static website HTML/CSS/JavaScript. Dapat di-host pada layanan static hosting atau web hosting yang mendukung file statis. Domain belum dibeli; hubungkan domain setelah Owner memilih dan mendaftarkannya.

## Sebelum publikasi
- Owner meninjau seluruh teks, tampilan, logo, dan nomor WhatsApp.
- Verifikasi kembali nomor WhatsApp Business.
- Tambahkan kebijakan privasi dan ketentuan layanan yang telah disetujui.
- Verifikasi prosedur dan kewenangan layanan. Jangan menambahkan klaim aktivasi atau jaminan hasil yang belum terbukti.
- Uji tombol WhatsApp, tampilan mobile, dan aksesibilitas.
- Pasang domain dan HTTPS setelah persetujuan Owner.

## Catatan
Paket ini adalah versi produksi awal untuk review Owner, belum dipublikasikan ke domain dan belum terhubung ke backend, CRM, analytics, atau otomatisasi WhatsApp.
